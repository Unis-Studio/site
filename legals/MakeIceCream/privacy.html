Politique de confidentialité

1. Introduction

La protection de vos données est importante pour nous. Cette politique explique quelles informations sont collectées et comment elles sont utilisées.

2. Données collectées

Selon votre utilisation du service, nous pouvons collecter :

  • ID utilisateur Discord.
  • ID des serveurs utilisant le bot.
  • Paramètres de configuration du serveur.
  • Données nécessaires au fonctionnement des commandes.

Nous ne collectons pas de données personnelles inutiles.

3. Utilisation des données

Les données peuvent être utilisées pour :

  • Faire fonctionner les fonctionnalités du bot.
  • Améliorer le service.
  • Corriger les problèmes techniques.
  • Assurer la sécurité.

4. Stockage des données

Les données sont conservées uniquement pendant la durée nécessaire au fonctionnement du service.

5. Suppression des données

6. Services externes

Notre service utilise Discord. L'utilisation de Discord est soumise aux propres politiques de confidentialité de Discord.
